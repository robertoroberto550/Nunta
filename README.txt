APLICAȚIE INVITAȚII NUNTĂ

Deschide index.html într-un browser.

Funcții incluse:
- creare invitație personalizată
- fotografie pentru miri
- 4 modele: Romantic, Elegant, Minimal, Floral
- părinții mirelui și miresei
- nași
- locație și hartă Google Maps
- listă de invitați
- link separat de confirmare pentru fiecare invitat
- cod QR pentru link
- trimitere prin WhatsApp
- confirmare Particip / Nu particip
- număr persoane, meniu și mesaj
- centralizare răspunsuri
- tipărire / salvare PDF din browser

IMPORTANT:
Confirmările sunt salvate local în browser în această versiune. Pentru confirmări reale de pe telefoanele invitaților, aplicația trebuie publicată pe un host și conectată la o bază de date online (de exemplu Supabase).
